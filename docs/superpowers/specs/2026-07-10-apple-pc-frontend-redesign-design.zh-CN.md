# Apple 风格 PC 前端重构设计

## 目标

将现有 Jenkins 发布中心前端重构为克制、清晰的 Apple 风格桌面 Web 应用。在提升视觉层级、一致性和可用性的同时，保留全部业务行为、接口契约、路由和发布操作。

## 范围

- 仅支持 PC 网页端，最低实用视口宽度为 1024px。
- 保留 Vue 3、Vite、TypeScript、Vue Router、Pinia、Naive UI、Axios、ECharts 和现有图标库。
- 重构应用框架和全部现有页面：登录、仪表盘、Jenkins、发布计划、发布详情、执行历史和系统配置。
- 仅删除经过全仓库引用检查后确认无用的文件、样式、导入和资源。
- 不修改后端接口、请求参数、状态流转、权限逻辑和路由地址。

## 视觉方向

- 采用 Apple 桌面应用的视觉语言，不做营销官网风格。
- 使用 `#f5f5f7` 柔和浅灰画布、半透明导航表面、白色内容层、细中性边框和克制的带色阴影。
- 使用兼容 Apple 的系统字体栈，不下载字体，也不增加字体依赖。
- Apple 蓝作为唯一交互主色；成功、警告、运行中、禁用和失败颜色只表达业务状态。
- 外层容器使用 12-16px 圆角，内部控件使用更小圆角，保持清晰的嵌套层级。
- 避免装饰性渐变、过度毛玻璃、营销式超大标题和干扰发布操作的动画。

## 应用框架

- 保留固定的 PC 侧栏，承载五个一级导航入口。
- 将侧栏重构为浅色、轻微半透明的 macOS 来源列表风格，提供清晰的选中、悬停和键盘焦点状态。
- 保留紧凑顶栏，用于显示页面上下文和当前账号操作。
- 内容区域设置合理的阅读宽度，同时允许数据表格和日志使用可用的桌面宽度。
- 删除移动导航和移动端专用的响应式布局转换。

## 组件与状态

- 在现有全局样式和 Naive UI 主题覆盖中集中管理颜色、间距、圆角、阴影和字体令牌。
- 用安静的分组表面替代通用的边框卡片，只在层级确有需要时使用阴影。
- 运维表格保持紧凑、易扫描，使用轻量行分隔、清晰表头、等宽数字和明确的行操作。
- 保留深色日志控制台，并改善工具栏、对比度、换行和状态呈现。
- 保留清晰的悬停、按下、键盘焦点、加载、空数据、禁用和错误状态。
- 危险操作必须明显区分，但不能让所有操作拥有相同的视觉优先级。

## 页面行为

- 现有 Store、路由守卫、请求工具、筛选、排序、对话框、表单、发布控制和日志逻辑保持不变，除非展示调整确有需要。
- 仪表盘指标改为紧凑的概览区，不再使用通用等宽卡片阵列。
- 表单采用分组区域、对齐标签、一致控件宽度和清晰的校验反馈。
- 详情页按状态、主操作、任务进度、日志的顺序建立信息优先级。
- 登录页改为聚焦的桌面登录界面，不保留装饰性或示例内容。

## 无用代码清理

- 删除任何候选文件和导出符号前，先检查其全部调用和引用。
- 确认无引用后，删除 Vue 默认示例组件以及 Vue/Vite 默认资源。
- 删除未使用的 CSS、导入、注释代码和仅服务于移动端的媒体查询。
- 现有设计文档和验收截图默认保留；只有确认它们属于已废弃生成物而非项目输入时才删除。

## 验证

- 运行现有 UI 测试脚本。
- 通过现有 `npm run build` 执行 TypeScript 检查和 Vite 生产构建。
- 在 PC 视口检查全部路由，确认导航、表单、表格、对话框、发布操作、加载状态、空状态、错误状态和日志均可正常使用。
- 将原有失败与本次重构引入的回归问题分别记录。

## 非目标

- 不修改后端。
- 不迁移框架、组件库、路由、状态管理或图表库。
- 不增加新依赖。
- 不处理手机端和平板端布局。
- 不增加推测性组件框架或抽象层。

# 执行历史操作区与退出按钮设计

## 目标

修正执行历史页“同步外部构建”的视觉归属，并将顶栏账户胶囊替换为明确的退出操作。

## 执行历史页

- 从页面标题区移除“同步外部构建”。
- 使用现有 `NTabs` 的 suffix 区域，把按钮放在 Tab 行最右侧。
- 按钮仅在 `Jenkins 外部手动构建` Tab 激活时显示，继续复用现有 `syncExternalHistories`、`syncing` 和 `RefreshButton`。
- 页面标题区只保留标题说明与全局“刷新”，避免三个元素被 `space-between` 拉散。
- 移除按钮上的内联右边距，不增加新样式或组件。

## 顶栏退出

- 删除 Jenkins 头像和用户名显示，改为 `LogOutOutline` 小图标加“退出”文字按钮；图标复用已安装的开源 `@vicons/ionicons5`，不新增本地资源或依赖。
- 按钮继续调用现有退出请求和本地登录态清理逻辑。
- 点击按钮先弹出 Naive UI 确认框，文案为“确认退出当前账号？”，操作为“取消”和“退出”。
- 用户确认后才执行退出；取消时不产生请求。
- 顶栏按钮沿用现有高度、边框、悬停、按下和键盘焦点反馈，删除头像与用户名专用样式。

## 范围与验证

- 只修改 `frontend/src/views/history/index.vue` 和 `frontend/src/views/MainLayout.vue`。
- 不增加依赖，不改变路由或后端接口。
- 功能由用户人工验收；交付前运行前端构建检查。

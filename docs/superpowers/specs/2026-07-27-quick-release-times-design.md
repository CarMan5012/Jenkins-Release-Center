# 发布计划快捷时间设计

## 目标

在“创建发布计划”的调度时间选择器下方提供 `21:30` 和 `22:00` 两个快捷按钮。

## 行为

- 已选择日期：保留日期，只把时分改为按钮对应时间，秒和毫秒归零。
- 未选择日期：使用最近一次未来时间；今天尚未到该时间则选今天，否则选明天。
- 快捷按钮只在需要调度时间的发布类型中显示。
- 点击按钮后仍可通过日期时间选择器继续修改。

## 实现与验证

- 在现有发布计划页面增加一个小型时间计算函数和两个按钮，不新增依赖或组件。
- 在现有 UI 测试中覆盖两个按钮、已有日期替换和跨日选择规则。
- 运行前端 UI 测试和生产构建。
